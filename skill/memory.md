# 记忆技能

## 什么时候写记忆

用户的指令里出现"记住""记一下""别忘了""以后都""默认""以后要""帮我记着"等表达时，把对应内容存成长期记忆。

## 怎么写

用 `file:` 协议在项目根的 `memory/` 目录下新建一个 `.txt` 文件：

```file:memory/memory_主题简述.txt <<EOF
要记住的具体内容，写清楚即可
EOF
```

规则：

- 文件名：`memory_` + 简短英文/拼音主题，如 `memory_use_english.txt`、`memory_server_port.txt`。避免中文文件名。
- 内容：直接写要点，不要写"用户让我记住"这种元描述。
- 一条记忆一个文件，主题不同就分开存，别塞同一个文件。
- 写入后用一句话告诉用户已记住，不要长篇大论。

## 例子

用户："记住，以后回代码注释都用中文。"

```
```file:memory/code_comment_chinese.txt <<EOF
代码注释一律用中文
EOF
```

用户："记一下，我服务器公网 IP 是 1.2.3.4。"

```
```file:memory_server_public_ip.txt <<EOF
服务器公网 IP: 1.2.3.4
EOF
```

## 边界

- 用户只是讨论、闲聊、临时说明，没说"记住"，不要主动写记忆。
- 已有相同主题的记忆文件，先 read 看一眼，避免重复或矛盾；要更新就用 file: 覆写，不要建一堆近似文件。
- 记忆会自动拼进系统提示词，下次对话天然生效，不需要告诉用户"下次重启"之类。
- 不要把对话内容、敏感密码（除非用户明确要求）整段塞进记忆。
