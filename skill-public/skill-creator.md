# Skill 制作规范与指南

## 1. 核心原理
- **上下文加载**：系统扫描文件中全部有效且闭合的 ` ```! ` 简介块并合并内容，不限于第一个。建议把主要简介放在文件开头，便于按需查阅；嵌套在其他代码围栏中的示例不作为简介。
- **正文按需读取**：未读取的正文不会自动占用日常上下文 Token。用 read-x 读取后，实际回传内容会占用当轮上下文；开启工具结果留存时还会进入之后的用户提问，直至离开文本历史窗口、被压缩或清空。未读取的部分不会因此被保存。复杂流程可放在正文，按任务需要查阅。
- **按需启停**：每个 skill 默认启用。普通关闭只保留名字和绝对路径，可按需读取简介块和正文；开启“彻底隐藏”才从技能 Prompt 中移除该条目。隐藏不删除文件，也不改变文件访问权限。

## 2. 编写法则
- **简单 / 必备技能**：把环境变量、核心命令和安全规范直接简短精炼地塞进 ` ```! ` 简介块里，光写个简介块即可。
- **复杂技能**：简介块写核心索引，正文中放置长篇排查手册或复杂机制。
- **路径保持可移植**：文档示例可写相对项目根目录的路径（如 `skill-public/script/xxx/run.sh`），不要写死某台机器的用户名目录。实际使用 read-x、file-x、edit-x、sendfile-x 或 grep-x 的路径参数时，须结合系统给出的当前运行目录转换成真实绝对路径；run-x 使用相对脚本路径前先切到真实项目根目录。

## 3. 简介块范例

好的简介块（简洁、含命令、含安全提示）：

```
便签技能：一键部署一个轻量私有网页便签。功能包括账号密码登录、便签列表、新建/编辑/删除、标题与正文搜索。安装: sudo bash skill-public/script/notes/install.sh install。更新: sudo bash skill-public/script/notes/install.sh update。卸载: sudo bash skill-public/script/notes/install.sh uninstall。默认端口 8899，部署时交互填写端口、账号、密码。
```

要点：一句话说清功能 → 三条核心命令 → 关键默认值。不展开细节，细节放正文。

## 4. 目录规范
- 公有技能文件：`skill-public/<技能名称>.md`
- 私有技能文件：`skill-private/<技能名称>.md`（不进仓库、更新不覆盖）
- 公有配套脚本：`skill-public/script/<技能名称>/`
- 私有配套脚本：`skill-private/script/<技能名称>/`
