# 上传附件版本管理

上传附件仍可在原路径修改；普通聊天的每次模型请求稳定读取磁盘当前完整内容，不改为按需读取、不减少已有附件。版本留存只用于追溯和恢复，不把旧版副本全部送入 AI。

## 原件与最近十版

- 新的普通文件、照片和相册附件：确认接收前保存独立的原始字节副本。副本不使用硬链接，之后改写原路径不会改变原件。配置/提示词/黑名单导入、生成媒体、工具冻结快照不经过这条原件备份流程。
- 按 SHA-256 去重，保存上传原件（不淘汰），另外最多保留最近 10 个不同内容版本；当前已保存版本始终保留。重复读取相同内容不重复写文件或增加条目。
- 文件及索引存于 `xgent_storage/attachment_versions/<附件身份>/`，跨进程文件锁串行化，先完整写入副本、再原子发布 JSON 索引，最后清理超限的中间版本。清理失败宁可保留多余字节，不破坏有效索引。
- 旧附件首次留版标记“升级后首次保存版本”，不声称是最初上传原件。程序只保留成功观察到的内容，两次读取之间未观察到的外部改写不能凭空恢复。
- 新上传原件备份失败不确认接收；Web 原来的 HTTP 接收回执现在等到备份与附件关联保存完成，不等待模型回答。收到接收超时时应先刷新核对，不盲目重复上传。
- 普通聊天遇到版本存储失败，仍可使用当次稳定读取的完整当前内容，并注明“未能留存版本”。当前附件标明 SHA-256，历史工具结果仍代表当时读取的冻结版本。缺失、不可读、损坏或写入不稳定的附件依然明确显示“附件暂不可用”，不自动拿旧版冒充当前文件。

## 网页查看、下载与恢复

聊天附件卡片和“文件与输出”列表提供统一“版本”入口，使用已有详情面板，不新增导航。原件/基准、当前磁盘状态和已保存版本分别显示；文本按其编码严格解码并分页，图片按保存版本的真实格式预览，版本下载读取校验后的字节。

“恢复此版本”需要确认目标和影响；只允许当前未归档、仍参与上下文的附件恢复。历史/归档附件可看和下载旧版，重置或压缩不会删除版本，永久删除对话使关联接口失效。底层文件的物理清理沿用现有附件策略。

恢复会短暂占用原跨进程全局执行位，忙时拒绝，不替用户停止任务。校验会话 generation、当前文件指纹、版本副本校验和及路径边界；先保留当前可读取内容，再原子替换原路径，并条件更新元数据。当前文件不可读、备份失败、符号链接或并发冲突时不覆盖；确定缺失的文件允许恢复。若数据库提交失败，且文件尚未发生后续修改，回滚到恢复前内容；并发写入发生后不反过来覆盖它，并保留版本供核对。

恢复不新发聊天消息、不运行模型、不恢复暂停队列。相关卡片原地刷新，正文、时间、附件身份不改变。后续请求继续提供磁盘当前完整内容；既有工具快照和压缩归档不改写。

## 兼容接口

数据库结构不变，附件引用可增加 `versions` JSON 摘要；版本索引和副本留在独立文件目录。展示描述增加 `versions_id`，以记录 ID 与稳定附件身份定位，而不是暴露任意服务器路径接口。

- `GET /api/workbench/artifacts/versions`：`conversation_id`、`id`；返回当前状态、generation、可恢复标记、指纹与已保存版本。
- `GET /api/workbench/artifacts/version_preview`：另传 `version_id`、`offset`；偏移以解码后字符计，一页最多 65,536 字符，保持同一版本，不混入当前文件。
- `GET /api/workbench/artifacts/version_download`：另传 `version_id`；普通下载为 attachment。`inline=1` 只允许安全的图片类型，HTML/SVG 不在同源嵌入执行。响应带 `nosniff`、私有禁止缓存与 CSP。
- `POST /api/workbench/artifacts/restore_version`：`conversation_id`、`id`、`version_id`、`generation`、`fingerprint`、`confirm:true`。鉴权/同源校验沿用原接口；预期冲突返回 UI 错误，不新建聊天报错记录。
- `attachment_changed` 事件更新可见卡片并使文件列表缓存失效，不重建整个历史或强拉到底。

版本列表与下载在磁盘读取后再次校验关联，已删除的会话不能利用旧链接继续下载；越界、校验损坏与失效恢复请求均拒绝。升级时连同数据库和 `xgent_storage/` 备份，不删除 `.turn.lock` 或版本存活锁来“解锁”。

## 验证

专项测试覆盖同长度修改、编码/图片变化、原件独立副本、去重和十版上限、读写/索引失败、旧版分页和下载、缺失恢复、不可读拒绝、并发冲突、取消请求等待恢复收尾、数据库回滚以及旧关联权限失效。浏览器使用隔离数据验证桌面/手机、明暗主题、来源跳转和卡片原位更新，不操作真实 Bot 或模型。
